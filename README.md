Movies Galore 🎬

A modern movie search app built with HTML, CSS, and JavaScript using the TMDB API.

Features
Search movies by title
Load trending movies on page load
Display movie posters, titles, ratings, and release years
Click movie cards to open TMDB movie pages
“Movie not found” error message
Responsive layout
Smooth hover effects and animations
Reusable render function for search and trending movies
Technologies Used
HTML5
CSS3
JavaScript
TMDB API
Fetch API
What I Learned
Fetching API data with fetch
Using async/await
Rendering arrays with forEach
Creating reusable render functions
Handling empty API results
Working with objects and nested data
Building responsive movie card layouts
Separating fetching logic from rendering logic
